# Monday

시험까지, 하루씩.

대학생을 위한 Windows 시험 공부 플래너입니다. 과목별 시험일과 범위, 목표 회독 수를 정하면 시험 전날까지 공부 계획을 나눠 배치합니다.

[Windows 배포판 다운로드](https://github.com/yohan-is/monday-planner/releases/latest)

## 주요 기능

- **과목별 시험일과 D-day** — 정확한 시험 날짜와 남은 공부일을 확인합니다.
- **회독 계획** — 단원·챕터·주차별 범위를 나누고, 각 회독에서 전체 범위를 순서대로 공부합니다.
- **자동 일정 배치** — 나눌 횟수를 비워두면 남은 날짜에 맞춰 공부 범위와 날짜를 정합니다.
- **과목 우선순위** — 중요도를 직접 지정하거나, 공부할 날이 적은 과목부터 추천받습니다.
- **진도 관리** — 공부를 완료하면 플래너와 할 일 목록, 회독별 진행률에 함께 반영됩니다.
- **바탕화면 위젯** — 주간 플래너와 오늘 할 일을 별도 창으로 띄울 수 있습니다.

## 시작하기

**v1.1.0 이상**의 배포판 ZIP 파일을 내려받아 압축을 풀고 `Monday.exe`를 실행하세요. 설치는 필요하지 않습니다. 실행 파일과 같은 폴더의 파일은 함께 보관해야 합니다.

기존 버전을 사용 중이라면 **설정 → 앱 완전히 종료** 또는 트레이 메뉴로 먼저 종료하세요. 창만 닫으면 구버전이 계속 실행될 수 있습니다. 새 버전은 제목 표시줄과 설정에서 버전 번호를 확인할 수 있습니다.

최신 소스를 직접 실행하려면 아래 [개발](#개발)을 참고하세요.

### 1. 시험과 과목 등록

상단 **+ 시험 등록**에서 시험 이름, 시험 기간, 공부 시작일을 입력합니다. 시험이 하루라면 기간의 시작과 끝을 같은 날짜로 지정합니다.

과목마다 다음 내용을 정합니다.

| 항목 | 입력 예시 |
| --- | --- |
| 과목 | 미시경제학 |
| 과목 시험일 | 10월 21일 |
| 시험 범위 | 1–8주차 |
| 한 회독을 나눌 횟수 | 4번 또는 비워두기 |
| 목표 회독 수 | 3회독 |
| 중요도 | 자동, 높음, 보통, 낮음 |

과목 시험일은 등록한 시험 기간 안에서 선택합니다. 저장 전 미리보기에서 D-day와 회독별 공부 기간을 확인할 수 있습니다.

### 2. 공부 계획 만들기

**1–8주차를 4번씩 나눠 3회독**한다면 총 12번의 공부가 배정됩니다.

```text
1회독: 1–2주차 → 3–4주차 → 5–6주차 → 7–8주차
2회독: 같은 범위를 다시 공부
3회독: 같은 범위를 다시 공부
```

나눌 횟수를 비워두면 범위 개수와 남은 공부일, 목표 회독 수를 기준으로 자동 분할합니다. 일정은 공부 시작일부터 해당 과목의 시험 전날까지 배치합니다. 공부 횟수가 남은 날짜보다 많으면 하루에 여러 번 배정될 수 있습니다.

### 3. 먼저 공부할 과목 고르기

중요도는 **높음 → 자동·보통 → 낮음** 순으로 반영됩니다. 같은 중요도에서는 공부할 수 있는 날이 적은 과목이 먼저 나옵니다. 별도로 지정하지 않으면 **자동**으로 설정됩니다.

메인 화면의 과목 카드 또는 시험 계획의 **시험일·중요도 / 자동 배치**에서 수정할 수 있습니다. 시험일을 바꾸거나 재배치를 선택하면 미완료 공부만 다시 배치하며, 완료 기록과 회독별 범위는 유지합니다.

### 4. 일정 확인과 완료 표시

- 카드에 표시된 **1회독 · 1–2주차**를 보고 공부할 범위를 확인합니다.
- 카드를 누르면 내용·날짜·범위·메모·색상을 수정할 수 있습니다.
- 카드를 다른 날짜로 드래그하면 일정을 옮길 수 있습니다.
- 할 일 목록의 체크박스로 완료하고, 시험 계획에서 회독별 진행률을 확인합니다.
- 날짜가 정해지지 않은 일은 **나중에 할 일**에 적어둔 뒤 **+**로 선택한 날짜에 추가합니다.

## 바탕화면 위젯

상단 **위젯** 버튼을 누르면 주간 플래너와 오늘 할 일이 별도 창으로 열립니다.

| 위젯 | 사용 방법 |
| --- | --- |
| 주간 플래너 | 제목 표시줄로 이동하고, 창 테두리로 크기를 조절합니다. |
| 오늘 할 일 | 작업 표시줄을 제외한 모니터 오른쪽에 맞춰 표시됩니다. |
| 상단 핀 버튼 | 다른 창 위에 고정할지 선택합니다. |

위젯은 독립된 창이므로 **Win+D**를 누르면 다른 창과 함께 숨겨질 수 있습니다. 창을 닫아도 시스템 트레이에서 다시 열 수 있으며, 완전히 종료하려면 트레이 메뉴 또는 설정을 이용하세요.

## 저장과 백업

계획은 계정 없이 PC에 자동 저장됩니다. **설정 → 데이터 백업**에서 JSON 파일로 내보낼 수 있습니다.

- Windows 앱: Electron 사용자 데이터 폴더의 `planner.json`에 저장합니다. 플래너와 위젯은 같은 데이터를 사용합니다.
- 브라우저 미리보기: 해당 브라우저의 localStorage에 별도로 저장합니다. Windows 앱과 동기화되지 않습니다.

## 개발

Node.js 24 이상이 필요합니다.

```sh
npm ci
npm start
```

| 명령어 | 설명 |
| --- | --- |
| `npm start` | Windows 앱 실행 |
| `npm run dev` | 브라우저 미리보기 서버 실행 |
| `npm test` | 일정 배분·우선순위·저장·위젯 테스트 |
| `npm run build` | Windows x64 실행 폴더 생성 및 내용 검증 |
| `npm run verify:build` | 기본 실행 폴더가 현재 소스와 일치하는지 확인 |

브라우저 미리보기는 [localhost:5173](http://127.0.0.1:5173)에서 열립니다. 빌드 결과는 `release/Monday-win32-x64/`에 생성되며, `Monday.exe`를 실행하면 됩니다.

배포 전에는 빌드 후 `npm run verify:build`가 통과하는지 확인하고, 검증된 실행 폴더로 ZIP을 만듭니다. `git push`는 실행 파일이나 GitHub Releases 첨부 파일을 갱신하지 않습니다.
