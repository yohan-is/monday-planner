# Monday · 시험까지, 하루씩

블랙·화이트 바탕에 차분한 다섯 가지 포인트 색상을 사용하는 Windows 시험 공부 플래너입니다.

## 다운로드

[Windows 앱 다운로드](https://github.com/yohan-is/monday-planner/releases/latest)

`Monday-1.0.0-windows-x64.zip`을 받아 압축을 풀고 `Monday.exe`를 실행하세요. 설치 없이 사용할 수 있습니다. 실행 파일과 같은 폴더의 파일들은 함께 보관하세요.

## 실행

- 배포 앱: `release/Monday-win32-x64/Monday.exe` 실행. 이 폴더 안 파일들은 함께 보관하세요.
- 개발: `npm install`, `npm start`
- 브라우저 미리보기: `npm run dev`, `http://127.0.0.1:5173`
- 검증: `npm test`
- Windows 실행 폴더 생성: `npm run build`

개발 환경은 Node.js 24 이상을 사용합니다.

## 사용

1. 상단 **+ 시험 등록**으로 시험 이름과 시험 주를 등록합니다.
2. 과목별 총분량·단위·색상·공부할 요일을 선택합니다. 공부 시작일부터 시험 시작일 전날까지 정수 단위로 균등하게 배정합니다.
3. 우측 **나중에 할 일**에 필요한 일을 입력한 뒤 Enter를 누르고, **+**로 선택한 날짜의 할 일과 플래너에 함께 추가합니다.
4. 할 일이나 플래너 카드를 눌러 내용·날짜·분량·색상을 수정합니다. 체크박스로 완료합니다. 카드를 다른 요일로 드래그해서 옮길 수도 있습니다.
5. **위젯** 버튼은 독립된 주간 플래너와 우측 전체 높이 할 일 창을 엽니다. 플래너는 제목 표시줄로 이동하고 테두리로 크기를 조절합니다. 핀 버튼은 항상 위 표시를 전환합니다. 할 일 위젯은 작업 표시줄을 제외한 모니터 우측에 맞춰집니다.
6. 창을 닫아도 시스템 트레이에서 다시 열 수 있습니다. 앱 전체 종료는 트레이 메뉴 또는 설정에서 선택합니다.

## 데이터

네트워크 계정 없이 PC에 자동 저장합니다. 데스크톱 앱은 Electron 사용자 데이터 폴더의 `planner.json`을 원자적 파일 교체로 저장합니다. 모든 창은 동일한 메인 프로세스 상태를 사용합니다. 브라우저 미리보기 데이터는 브라우저 localStorage에 별도로 저장됩니다. 설정에서 JSON 백업을 내보낼 수 있습니다.

위젯은 테두리 없는 독립 창입니다. Windows 배경화면 자체에 삽입되는 기능은 아니므로 **Win+D**를 누르면 일반 창과 함께 숨겨질 수 있습니다. 플래너 기본값은 일반 창 순서, 할 일 기본값은 항상 위 표시입니다.

창 구현은 [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)와 [screen](https://www.electronjs.org/docs/latest/api/screen) API를 사용합니다.
